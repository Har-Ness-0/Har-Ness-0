## About

I'm a full-stack developer building web and mobile applications, with a focus on integrating AI into real products. I work across the whole stack: designing data models, building APIs in **Node.js** and **FastAPI**, and shipping interfaces in **React**, **Next.js** and **React Native**.

- Full-stack web and mobile development with TypeScript and Python
- AI integration: bringing ML models and AI APIs into production features
- Studying at **Itahari International College**, in partnership with **London Metropolitan University**
- Open to internships, freelance work and collaboration
